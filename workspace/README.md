# Diretório autorizado do JARVIS

Coloque aqui os documentos e projetos de teste que o assistente pode consultar e editar. O acesso padrão às ferramentas de arquivos é limitado a esta pasta. Configure outros diretórios no backend em `JARVIS_WORKSPACE_ROOTS` e reinicie.

Não coloque chaves, credenciais ou dados de outros projetos sem relação com a tarefa. As ferramentas não oferecem shell livre; testes Python executam o código deste diretório com os direitos do usuário.
